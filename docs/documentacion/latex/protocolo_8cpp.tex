void procesar\+Comando\+Serial (\begin{DoxyParamCaption}{}{}\end{DoxyParamCaption})}



Procesa un comando recibido por el puerto serie. 

Procesa los comandos serie STOP, ADC, ADC(x) y PWM(x).

Reconoce STOP, ADC, ADC(x) y PWM(x). STOP detiene el temporizador y pone la PWM a cero. ADC imprime una lectura y detiene el temporizador. ADC(x) inicia un temporizador con x segundos de periodo; PWM(x) ajusta el ciclo de trabajo a uno de diez niveles, de 0 a 9. \begin{DoxyNote}{Note}
La conversión de x se realiza con String::\+to\+Int(); no se valida expresamente si el contenido entre paréntesis es numérico.
\end{DoxyNote}
Procesa un comando recibido por el puerto serie.

Permite detener el temporizador, leer el ADC, iniciar lecturas periódicas o ajustar el ciclo de trabajo de la PWM.
